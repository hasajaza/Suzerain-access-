Suzerain Access - screen reader accessibility mod for Suzerain (Steam)

Install in three steps:

1. Close Suzerain. Extract this whole zip to any folder, for example your Downloads folder.
2. Open the extracted folder and double-click Install.cmd (select it and press Enter).
   The installer finds your Suzerain folder and copies everything into it.
   If it cannot find the game, it asks you to paste the game folder.
3. Start Suzerain and wait. The FIRST start takes several minutes while BepInEx
   prepares the game. Do not close it. You will hear:
   "Suzerain Access loaded. Press F1 for help, F9 for settings."

Manual installation instead of Install.cmd:
copy everything inside the folder named "files" into the Suzerain game folder
(the folder that contains Suzerain.exe), and allow Windows to replace files.

Screen readers: NVDA and JAWS work through Universal Speech. Without a screen reader the Windows voice is used.
JAWS users: if JAWS is silent inside the game, open JAWS Settings Center, choose Unity Player,
go to Miscellaneous and set Sleep Mode to disabled.

Keys: see KEYBOARD.md. Press F1 in the game to hear all keys.
This mod is for Suzerain build 3.1.0.1.175. It is unofficial and not affiliated with Torpor Games.
